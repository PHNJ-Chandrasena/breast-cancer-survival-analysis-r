# Breast Cancer Survival Analysis in R

## Overview
This project applies survival analysis techniques to the Wisconsin Prognostic Breast Cancer (WPBC) dataset.

## Objectives
- Kaplan-Meier survival estimation
- Log-Rank test
- Cox proportional hazards model
- Model diagnostics

## Tools
- R
- survival
- survminer
- dplyr

## Dataset
Wisconsin Prognostic Breast Cancer (WPBC) dataset
